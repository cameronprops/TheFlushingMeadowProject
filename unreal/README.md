# Unreal project area

This directory is an integration destination, not yet a compiled UE project.

The earlier `WorldFair1939` C++ first/third-person prototype exists in the existing research package but is uncompiled and covers only 1939/1940 logical states. Import it here after verifying UE version, input bindings, collision behavior, year switches, licensing and source consistency.

Target architecture is described in [Unreal implementation](../docs/UNREAL_IMPLEMENTATION.md). Place selected binary assets in Git LFS or reference them via Drive archival records; do not commit generated Unreal caches.
