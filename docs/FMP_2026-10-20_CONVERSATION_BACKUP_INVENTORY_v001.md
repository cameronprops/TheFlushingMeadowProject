## Conversation decisions and work history (reconstructed summary, NOT a word-for-word log)

1. User requested a coordinated Game Development Studio + Wolfram approach for FMP. Wolfram numerical geometry succeeded; the local Game Development Studio CLI and Unreal runtime were unavailable, so no native engine pass occurred.
2. The v005 Theme Center was inspected without changing the historic source or print models. Existing source 510 nodes, 62 overlay nodes, 573 assembled nodes and 558 visible mesh nodes. Static hash/geometry tests are not Unreal collision tests.
3. Read-only Trylon route audit improved discrete clearance and corner interpolation, but this DID NOT certify architecturally finished doorways or historic route fidelity.
4. Actual GLB Trylon renders showed the broad pre-existing cladding opening. The return route did not simply travel through intact exterior cladding, but door-specific architectural framing and historical accuracy remained unresolved.
5. A reversible provisional return-portal overlay was developed. Its elevated return doors are NOT the ground-level public Perisphere Entrance canopy/ticket lobby.
6. User emphasized the actual historic PERISPHERE ENTRANCE canopy/sign, the elegant curved/arched upper bridge, the two escalators and what visitors experienced inside the Trylon. Treat public entry lobby, enclosed escalator chamber, open return bridge and Helicline return as distinct architectural assemblies.
7. **IMPORTANT REJECTION:** A generated synthetic image was mistakenly shown as if historically grounded. User explicitly rejected it. NEVER treat that AI image, its ornamental bridge, canopy, flags or interior invention as an archival reference, measured geometry or sanctioned artistic direction.
8. Historic research identified photographs and an original period guide. The current v005 `Return_Bridge_Deck` is about 0.21336 m thick, a model proxy rather than the photographed curved bridge. The interior walls/finishes are still unverified.
9. Model-anchored six-object registration control GLB and synthetic-camera solver were created and archived. No actual photo-fit measurement against two verified historical camera frames has passed.
10. This audit verified only selected Drive packages and tracked gaps in exact chat preservation, high-resolution archival material, and stand-alone render files.
